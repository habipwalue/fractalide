# Fractalide Examples

This directory contains example applications built using the Fractalide architecture. Each example demonstrates different aspects of Fractalide's dataflow programming model.

## Available Examples

- **Chat Application**: A real-time chat system with rooms, users, and messages

## Coming Soon

- **Calculator**: A simple calculator demonstrating basic Fractalide concepts
- **Image Processing Pipeline**: A pipeline for processing images through various transformations
- **Web Server**: A simple HTTP server with routing capabilities

## Overview

For a comprehensive overview of all examples and the Fractalide architecture, see the [Fractalide Examples Overview](../fractalide_examples_overview.md) document.

## Running Examples

Each example has its own README with specific instructions for building and running the application.
